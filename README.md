A better way to view Rice's course catalog!
What this does better than the official [Rice courses page](https://courses.rice.edu):
- Searching for courses across years. Seeing how a course changes or how often it is offered is valuable information.
- Consolidating course and instructor evaluations, course syllabus, and course descriptions in one place. *This feature is only available to users with a Rice NetID.*

The site is public at [ricecourses.vercel.app](https://ricecourses.vercel.app)
